01 · Featured work

Phygital Android agent app

KocharTech · live video-demo platform for multi-tenant customer support

Problem

Agents worked from the web dashboard. A mobile agent app had to keep every web feature (login, lobby, routing), and the call itself had to run natively so Android screen sharing (MediaProjection) works.

Approach

I led the R&D and proposed a hybrid architecture: keep the existing React web app in a WebView, and hand the call itself to a native screen built on the Daily WebRTC SDK. I proved it with a solo Kotlin proof of concept before building it out.

Result

Now in production with the platform's agents. It reuses 80–85% of the existing code and cut agent setup cost by 90%, with native screen share, chat, annotations, and recording.

What I built

  • A solo 570-line Kotlin native module and React Native view manager on the Daily Android SDK, to prove the approach
  • A typed WebView-to-native bridge with validated messages, plus login reuse through Android's shared cookie store
  • A platform-independent call-lifecycle hook, extracted from ~1,700 lines of web code, that prevents duplicate rooms and leaked calls
  • Native screen share, chat, pinning, waiting room, synced annotations, auto-recording, and audio routing
  • A patch to react-native-webrtc for TextureView rendering, Android foreground services, and ~300 tests
